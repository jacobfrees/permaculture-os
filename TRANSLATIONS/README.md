# TRANSLATIONS

Every language. Offline-first. Diagram-first.

## Method

1. Kernel documents are written in **kernel English** (~1,000 common words) +
   diagrams, so they are simple to translate and machine-assistable
2. Native speakers refine meaning and idiom
3. Audio versions for oral cultures; picture-first manuals where literacy varies
4. Each language directory mirrors the kernel structure exactly

## Starting Languages

- English (source)
- Spanish, French, Arabic, Swahili, Hindi, Portuguese, Mandarin, Indonesian —
  prioritized by the regions where food insecurity is highest
