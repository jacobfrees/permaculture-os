# 10-LAW-NAVIGATION — North Carolina Case Study (template for other states)

*This is the first Legal Atlas entry — the format every community's legal report should follow.*

## JURISDICTION
North Carolina, USA. Statewide uniform residential code enforcement (2018 NC
Residential Code effective; 2024 code usable as alternate at owner request).
Rural counties generally practical; urban counties strict.

## THE DOORS THAT WORK
| Need | NC Path |
|---|---|
| Build your own home w/o contractor license | Owner-builder exemption, G.S. 87-1(b)(2) + affidavit G.S. 87-14 — sole occupancy ≥12 months, personal superintendence |
| Farm buildings | Agricultural exemption G.S. 87-1(b)(3) — own land, own use, farming business |
| Small non-structural work ≤$40k | G.S. 160D-1110(c) permit exemptions (with listed exceptions) |
| Unconventional walls (tire/earthbag) | Alternative materials provisions — engineer stamp required |
| Community land | Land trust / conservation easement; NC land trust network is strong |

## THE GATES (what will block you if ignored)
- Septic: mandatory state-approved system (130A-335); open blackwater planters refused
- Perc test BEFORE land purchase
- Watershed zones near reservoirs add water/septic restrictions
- No "no-code counties" — NC enforces statewide
