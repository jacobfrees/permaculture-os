# PROTOCOLS — How Communities Connect

Four core protocols let any community running this kernel connect to any other,
with or without internet.

## 1. Adaptation Patches (`adaptation-patch.md`)
Field reports as structured patches: what failed, what worked, where tested.
Pulled by every node. The kernel evolves through thousands of real test sites.

## 2. Surplus ↔ Need Routing (`surplus-need-routing.md`)
A community with surplus finds the community with a gap. Food, seeds, tools,
materials, skills — routed by need, settled in reciprocity, never in debt.

## 3. Crisis Mutual Aid (`crisis-mutual-aid.md`)
Pre-agreed mutual aid: each community publishes what it can send in a crisis
(food stores, tools, people, shelter capacity). Flood/fire/drought alerts
propagate through the mesh in minutes.

## 4. Fellowship Matching (`fellowship-matching.md`)
Communities find peers with the same climate driver, governance experiments,
or specialties — and trade knowledge deliberately.

## Federation Principles

- **Email, not Facebook** — every community runs its own node; nobody owns the network
- **Offline-first** — mesh (LoRa/WiFi/phone relays) carries everything; the
  internet is an accelerator, never a requirement
- **No center** — standards evolve by rough consensus and running code, like
  the protocols that run the internet itself
